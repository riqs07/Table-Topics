How rich can the art get?

A study, all drawn in code as vectors: two course headers and seven lesson tiles at the level of Wellspoken’s illustrations, each next to today’s flat tile. Same blob, same colours; what changes is layering, light, texture and a scene instead of an icon.

What makes them richer

  • A scene, not an icon: a place, a moment, something happening (ice melting, a dart landing).
  • Depth: three layers (far shapes, middle, the character up front) with lighter colours further back.
  • Light: soft gradients, a light source, glows and long shadows.
  • Texture: a fine grain over everything, so it reads as illustration, not clip art.
  • A story in one glance: the lesson’s idea acted out, not a symbol next to the blob.

Ways to get there

  1. Me, in code (what you see here). Consistent with the cast, themeable, animatable, tiny files. Slower per piece, and painterly detail is out of reach.
  2. An illustrator for a style guide plus key art. The best quality. They draw the cast and 5–10 hero pieces; I build the rest to match.
  3. AI image tools outside this session (with a strict style prompt and the cast as reference), cleaned up and vectorised. Fast and cheap, but hard to keep consistent across 70+ tiles.

My suggestion: decide the style with a few pieces like these, then choose. If you like this level, I can do it; if you want more painterly than this, bring in an illustrator for the style guide.
